# Gary says

Ask Gary a question, he tells you exactly what to do. No installs, no build
step — this is just one HTML file.

## Put it on GitHub Pages

1. Put `index.html` and `.nojekyll` in your repo (root folder, or a `/docs`
   folder — your choice).
2. On GitHub: go to your repo's **Settings → Pages**.
3. Under "Build and deployment", set **Source** to "Deploy from a branch",
   pick your branch (usually `main`), and the folder you used (`/ (root)`
   or `/docs`).
4. Save. GitHub will give you a live link in a minute or two, usually:
   `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

That's it — no other steps needed. Any time you edit `index.html` and push,
the live site updates automatically.

## Note

Gary's answers here are picked from a set of pre-written sassy lines rather
than generated live by AI — this keeps things simple with zero setup and no
API key to manage. If you ever want Gary to respond to the *specific*
question you type (using AI), that needs a small backend to keep an API key
safe — a bigger step, happy to help with that later if you want it.
